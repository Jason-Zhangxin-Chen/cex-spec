# 多活高可用 CEX 交易系统 · IcePanel 设计项目

多活高可用中心化加密货币交易所（CEX）的架构设计文档，最终交付为 **IcePanel 风格的设计页面** 与可直接导入 IcePanel 的 **Model-as-code 模型**。

> 客户为中文用户 —— 所有交付内容（页面、文档、模型名称与描述）一律使用中文。

## 目录结构

```
cex_icepanel/
├── spec.md                      # 客户提供的系统规格说明（权威依据）
├── improves.md                  # 改进项（预交易集群等，已并入 spec 附录）
├── design-review.md             # 设计评审：缺失组件与连接关系建议（v2）
├── cex-trading-system.html      # 输出页面（按章节组装）
├── icepanel-landscape.json      # IcePanel Model-as-code 模型（155 对象 / 35 连接）
├── import_to_icepanel.py        # 导入脚本（API key + landscape ID 即可运行）
└── render_*.png                 # headless 渲染校验截图（可随时重新生成）
```

## 工作流程

1. **读取输入** —— 客户提供文字规格说明（如根目录 `spec.md`）为权威依据；若提供设计图（放入 `inputs/`），由于会话图片通道可能失效，先用 `rapidocr-onnxruntime` 做 OCR（文字 + 坐标），再用 OpenCV 检测框图与长边界线，还原原始结构。
2. **绘制页面** —— 在 `cex-trading-system.html` 中按 IcePanel 风格重绘（点阵画布、分组虚线框、分类色边框、可悬停对象）。页面按章节组装：**第 1 节固定为「系统概览」**，后续章节随 spec 新增内容递增，末尾保留「导入 IcePanel」节。
3. **同步模型** —— 更新 `icepanel-landscape.json`（对象 ID 保持稳定，重复导入即 upsert 更新而非重复创建）。
4. **校验** —— 解析校验 SVG（框/连线/标注几何），并用 `google-chrome --headless --screenshot` 渲染截图人工确认。

## 导入 IcePanel

```bash
# 1. 获取 API key（Growth / Scale 套餐）：icepanel.dev/integrations/api-sdk
# 2. 在 .env 中配置
export ICEPANEL_API_KEY=...

# 3. 列出可访问的组织与 landscape
python3 import_to_icepanel.py --list-orgs

# 4. 导入 / 更新模型
python3 import_to_icepanel.py <landscape-id>
```
